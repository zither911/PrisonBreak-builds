# Prison Break — builds

Windows builds of Prison Break. **Downloads are under
[Releases](https://github.com/zither911/PrisonBreak-builds/releases/latest).**

Unzip anywhere and run `PrisonBreak.exe`. Nothing to install.

This repository holds the shipped zips and nothing else — no source. It is
public for one reason: it lets the game check for a newer version and lets you
download one without any account, token or login. The game itself carries no
credentials of any kind.

Found a bug? There is a **Report a bug** button in Settings. It sends the level
and its seed, a screenshot and the log along with whatever you type, which is
usually the difference between a bug that gets fixed and one that cannot be
reproduced.
